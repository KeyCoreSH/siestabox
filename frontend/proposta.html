Escopo & Proposição da KeyCore

Solução de software e IoT focada em eliminar gargalos operacionais: liberação remota instantânea de portas, precificação por Pix e monitoramento contínuo de manutenção e temperatura.

Desenvolvida pela KeyCore Tech Hub com base em microserviços Node.js/Fastify, banco de dados geoespacial PostgreSQL/PostGIS e protocolo MQTT para trancas e sensores de campo.

Cronograma de Entrega (30 Dias / 3 Sprints)

Sprint 1 — Fundação (10 dias)
  • Modelagem PostgreSQL + PostGIS
  • API Fastify + Docker Container
  • PWA Cliente de busca por local
Sprint 2 — Core & IoT (10 dias)
  • Gateway de Pagamento Pix
  • Broker MQTT para tranca eletrônica
  • Emissão de QR Code e validação
Sprint 3 — Operações (10 dias)
  • Dashboard de gestão da frota
  • Métricas de ocupação e higienização
  • Homologação e entregáveis finais

Arquitetura de Sistemas & Infraestrutura

Definição de contêineres Docker e modelagem de banco de dados geoespacial PostgreSQL/PostGIS.

docker-compose.yml

version: '3.8'

services:
  postgres:
    image: postgis/postgis:16-3.4
    container_name: siesta-postgres
    ports: ["5432:5432"]

  redis:
    image: redis:7-alpine
    ports: ["6379:6379"]

  mosquitto:
    image: eclipse-mosquitto:2.0
    ports: ["1883:1883"]

  api:
    build: .
    environment:
      PORT: 8080
      DATABASE_URL: postgresql://...
    ports: ["8080:8080"]

schema.sql (PostgreSQL + PostGIS)

CREATE EXTENSION IF NOT EXISTS "postgis";

CREATE TABLE unidades (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    codigo_patrimonio VARCHAR(50) UNIQUE NOT NULL,
    local_id UUID REFERENCES locais(id),
    status status_unidade DEFAULT 'disponivel',
    bateria_nivel INT DEFAULT 100,
    ar_condicionado_setpoint NUMERIC(3,1) DEFAULT 22.0,
    porta_trancada BOOLEAN DEFAULT TRUE
);

CREATE INDEX idx_locais_posicao 
ON locais USING GIST (posicao);
